# SC17 修复与验证报告

日期：2026-10-16。此次以 SC17 为基础直接修复代码，修改了 10 个原有文件，新增了数值契约、完整轨迹验证和有限子步重算等模块。原有 25 个 Python 文件已备份在本目录的 `original/`，并逐一核验备份 SHA-256。SC15、SC16 和 SC17-0 的代码、模型及既有诊断报告未修改。

**代码层面的确定性错误和入口问题已修复；浓度精度仍须通过完整数据重新训练来验收。** 本次完成了回归测试、4,800 条真实转移回放、实际单步/多步短训和独立验证。短训模型仍漏点火，修复后的验收逻辑正确拒绝将其保存为最佳模型。

## 已实施的修复

| 问题 | 修复后的行为 | 主要文件 |
|---|---|---|
| 宏观 asinh 标签不受限，解码却被截断到 ±20，导致理想标签也无法还原点火段浓度 | 在可表示范围内使用真实 asinh 逆变换；数值超出表示范围时明确失败，不再悄悄改变预测 | `numerical_contract.py`、`train_sc_v68.py` |
| raw 状态和守恒损失的硬上限产生零梯度 | 保留未限幅的宏观候选和微观 log 候选；守恒损失改用具有恢复梯度的 smooth-L1。线性质量分数在物理域内精确，Y>1 区域使用有梯度的延拓以避免指数溢出 | 同上 |
| 去除限幅后，大 raw 值与 STE 差分相消，污染最终守恒状态 | STE 改写为“精确投影值 + 已先计算为零的 raw 差”；独立审计实际返回的宏观/微观状态 | `train_sc_v68.py` |
| 微负惰性值、float32 反标准化相消误差使合法数据无法输入 | 仅清理严格受表示误差界约束的微负惯性/宏观输入；真实负值仍保留并拒绝 | `numerical_contract.py` |
| 可行投影目标被拒绝，局部残差又在长轨迹累积 | KL 内部使用 float64、更精确的元素目标和停止条件；Dykstra 未收敛时增加小规模非负等式优化回退；输出转回原 dtype 后重新验收 | `physical_projection_contract.py`、`train_sc_v68.py` |
| 合法点火温升超过 500 K 被拒绝 | NASA7 解已满足能量残差和支持的温度边界时接受其实际温升；不剪裁温度。旧线性近似仍受原参数约束 | `train_sc_v68.py` |
| 主循环的反馈索引遗漏惰性物种 | 当前惰性组成随自主反馈传递，不从下一时刻参考状态补入 | `train_sc_v68.py` |
| autonomous 预设噪声与严格物理输入契约冲突 | 所有 autonomous 预设统一采用零反馈噪声和 constrained 反馈；显式不兼容配置仍拒绝运行 | `train_all_v68.py` |
| 连续 P/D 分支可能溢出，纯衰减刚性边界不连续，NO 分组不一致 | 在 log 域积分，覆盖纯生成、纯衰减和刚性平衡；诊断率使用 double 并检查范围；P/D 与旧双分支均将 NO 纳入宏观组 | `kinetics_parameterization.py`、`train_sc_v68.py` |
| 验证记录 raw 微观输出时混入受约束候选 | raw 指标使用明确的 raw 字段；raw 分支采用相同的输出布局，不再切换到 legacy 解码 | `validate_sc_v68.py` |
| raw 自主诊断遇负浓度会中止整个验证 | 记录该批 raw 分支的失败位置和原因，后续 raw 轨迹为 NaN、无有效样本的统计为 None；继续完成部署分支。部署分支自身失败仍明确终止 | 同上 |
| 物种指标、真实反馈和 best 保存逻辑不一致 | 选模指标按实际 constrained 反馈计算，raw 监督损失保留；窗口峰值、峰值时刻及终点误差进入评分；全部 best 保存入口统一受完整轨迹验收控制 | `species_validation_protocol.py`、`train_sc_v68.py` |
| 有完整轨迹指标模块，却没有可执行与选模闭环 | 新增独立 NN/Cantera 完整轨迹 runner，接入训练完整验证轮次；漏点火、假点火或物理失败均不具备选优资格 | `complete_validation.py`、`test/benchmark_autonomous_h128.py` |
| 数值失败时缺少合规的子步重算 | 独立完整轨迹 runner 支持最多四层二分；每个子步重新调用模型，后一子步从前一子步实际 T/P/Y 开始，结束后恢复外层规定 dt | `autonomous_integrator.py` |
| 数据构建器缺失导入、没有可加载的 metadata；v72 批量验证入口缺项 | 抽取本地共享工况表，移除缺失脚本依赖；构建后同步真实行数和机理元信息；恢复两个 v72 方案扫描及正确更新规则；压力分层改为 atm 单位下的 5 atm 分箱 | 构建器、`benchmark_cases.py`、两个验证入口 |
| 已记录源码 hash，却未校验当前运行代码 | 新运行契约为 `sc17_repaired_kinetics_v2`，校验当前核心源码、机理和 scaler 内容；固定验证工况 hash、反应器筛选规则及 sentinel 规格 | `experiment_manifest.py` 等 |

物理审计容差没有放宽：质量残差上限仍为 5e-6、元素残差上限仍为 1e-6、输出必须非负。独立轨迹同时检查能量残差 ≤10 J/kg、EOS 相对残差 ≤1e-5。训练和窗口验证保持失败即停止；只有独立完整轨迹 runner 实施明确记录的子步重算，避免记录的监督对象与实际反馈状态不一致。
